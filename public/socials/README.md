# Social marks

Recognizable brand paths from Simple Icons v11.15.0, retained locally so links do not depend on a third-party image service.

Source: https://github.com/simple-icons/simple-icons/tree/11.15.0/icons

The nine SVG files provide the eight social profiles and the separate WhatsApp action. CSS masks adapt the monochrome marks to the portfolio's two themes. Brand ownership remains with the respective platforms.
